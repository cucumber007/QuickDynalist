# Agent instructions

## Documentation style

- Name Markdown files with caps kebab-case, for example `PULL-FIRST.md`.
- When referencing code files in documentation or code comments, use the file path without package names and path. For example, prefer `/jobs/SyncJob.kt` or `SyncJob.kt`, not `com.louiskirsch.quickdynalist.jobs.SyncJob` or `app/src/main/java/com/louiskirsch/quickdynalist/jobs/SyncJob.kt`.
